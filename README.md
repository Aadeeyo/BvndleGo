# BvndleGo

Website for BvndleGo: GoCar, GoBus and GoCharge. **Move Better.**

Everything is in a single file, `index.html`, with no build step.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root. The site goes live at `https://<username>.github.io/BvndleGo/`.

## Before launch
- The forms (the Move Better flow and each service page) are front-end only. Connect them to the CRM or a form endpoint.
- Values in the example screens (arrival times, battery %, coin balance, charger locations) are illustrative.
- The logo is drawn in SVG. Replace it with the official asset if needed.
